# SyntaxClipper by Syntax Nepal

Autonomous local video clipping studio for vertical short-form content (YouTube Shorts, TikTok, Instagram Reels, Facebook Reels).

## Features
- **4-Layer Game Detection**: Native Direct3D and background process monitoring to prevent FPS drop while gaming.
- **3-Tier Performance Modes**: Game Paused, Eco Mode (CPU multitasking), and Turbo Mode (NVENC hardware acceleration).
- **Multi-Platform Publishing**: Direct YouTube Data API v3 integration, unified social API connectors, and local folder export.
- **3-Way Facecam Layouts**: Auto-Detect, Split 42/58, and No-Facecam Full-Screen (9:16).
- **Interactive Manual Studio**: URL inspection, preview frames, and visual cropping.

## Getting Started
1. Run `start_syntaxclipper.bat` to launch the local studio.
2. For silent execution without console windows, use `start_syntaxclipper.vbs`.
3. To stop all services, run `stop_syntaxclipper.bat`.
